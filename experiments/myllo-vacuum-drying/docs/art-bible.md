# Art Bible · Myllo Vacuum Collection Pilot

## Visual direction

- 9:16, 1080×1920, 24 fps.
- Warm off-white paper field for product context.
- Dark hand-inked product reconstruction.
- Restricted editorial palette from the Procedural Film house palette.
- Red accent owns the vacuum arm / causal collection action.
- Blue is wet-state information.
- Sage is dry-state information.
- One cool blueprint macro plate is allowed for the explanatory middle.
- Sparse texture, no comic-panel clutter, no photoreal imitation.
- Typography supports the action and remains secondary.

## Product grounding

Geometry is based on the owner-controlled C1 Mini layered-object prototype:
- dark chassis;
- mounted elliptical record;
- centre clamp;
- right-side vertical vacuum tower;
- pivoting vacuum arm;
- two front controls.

The pilot deliberately preserves object identity over fine industrial-design fidelity. It must never become a generic floating nozzle over a generic disc.

## Motion language

Primary:
- continuous record rotation cue;
- wet-state reveal;
- sourced vacuum-arm pivot;
- distinct engagement state;
- wet → collection zone → dry causal boundary;
- release + return to parked orientation.

Forbidden as primary event:
- pan/zoom on a still;
- generic crossfade;
- decorative particle replacement for collection;
- caption-only action;
- camera motion hiding absent object motion.

## Typography

Requested brand families:
- Exo 2 for display;
- Montserrat for support.

This pilot does not yet pin exact font files inside the Docker renderer, so typography is evaluation-only and not canonical.
