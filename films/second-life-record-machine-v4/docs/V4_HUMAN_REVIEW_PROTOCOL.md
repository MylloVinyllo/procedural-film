# V4 Human Review Protocol — Machine-Cleaning Refinement

Purpose: verify that the V4 cleaning stage is understandable without prior knowledge of the machine.

## Pass 1 — blind story read

Watch the master once without reading the storyboard.

Immediately answer in one sentence:

> What happened in the film?

The minimum successful read is:
- dirty/noisy record;
- machine cleaning;
- visible cleaning stages;
- cleaner result;
- second playback feels better.

## Pass 2 — machine recognition

Without naming the brand from memory, answer:
- Did the black device read as a dedicated record-cleaning machine?
- Could you distinguish it from the turntable?
- Did the front controls / body / two working nodes make sense as one machine?
- Did the 3/4 camera help you understand the object?

If not, note the first frame where the machine looked ambiguous.

## Pass 3 — process comprehension

For the five cleaning shots, write what you think is happening before looking at the labels:

1. machine reveal / record placement;
2. solution / supply-brush engagement;
3. brush cleaning + reverse rotation;
4. vacuum collection / drying;
5. before / after groove comparison.

Then compare your read to the on-screen stage labels.

The labels succeed only if they reinforce visible physical action rather than replace it.

## Pass 4 — vacuum proof

This is the critical V4 test.

Answer:
- Did you understand that the right-side node was removing liquid/contamination by vacuum?
- Was the wet-before / dry-after material change visible?
- Did the vacuum node look different from the brush/supply node?
- Did the sound help identify the vacuum event?

## Pass 5 — before / after proof

Answer:
- Were the two groove panels obviously BEFORE and AFTER?
- Did they look like the same kind of groove area rather than unrelated graphics?
- Was the difference concrete enough to see without a voice-over?
- Did the AFTER side remain believable vinyl rather than becoming magically pristine?

## Pass 6 — craft / style

Note the weakest examples of:
- hands;
- record shape / ellipse / groove detail;
- sleeve;
- machine hardware;
- panel transitions;
- text treatment;
- camera depth;
- secondary motion.

Then compare V4 to Butterfly only on concrete craft dimensions:
- drawing specificity;
- number of meaningful moving systems;
- organic form quality;
- scene depth;
- transition sophistication;
- overall attractiveness.

## Useful feedback format

`time / scene → what I understood → what remained unclear`

The most important V4 human-review outputs are:
1. one-sentence story;
2. whether the machine was immediately recognisable;
3. whether PUMP/brush/REVERSE/VACUUM stages were distinguishable;
4. whether vacuum removal was understandable;
5. whether BEFORE/AFTER was obvious;
6. which object still looked most artificial;
7. which Butterfly quality remains furthest away.
