# V4 Brief — Second Life of a Record / Machine-Cleaning Refinement

Date: 2026-09-27
Branch: `film/second-life-record-machine-v4`
Project path: `films/second-life-record-machine-v4`

## Status inherited from V3

V3 is frozen as a **technical pass**.

Human review established that the broad story is understandable, but the cleaning stage is still too ambiguous without prior knowledge.

V4 is therefore not a new subject and not a new pipeline experiment from zero.
It is a controlled refinement of the accepted V3 story using the same native Procedural Film workflow and the same stream-safe transaction protocol.

## Subject sentence

A record collector hears an unpleasant dirty record, places it on a recognisable Myllo Vinyllo vacuum record-cleaning machine, sees the machine apply/engage the cleaning process and vacuum contamination away, verifies visibly cleaner grooves, then replays the record and enjoys the improved result.

## V4 primary question

Can Procedural Film carry a **brand-specific, concrete product process** clearly enough that a first-time viewer understands:
- what the machine is;
- what it is doing;
- which cleaning phase is happening now;
- what changed on the record;
- why the second playback is different?

## Mandatory human-review carry-forward

V4 must:
1. preserve the V3 story spine that already works;
2. redesign the cleaning section as the main hero sequence;
3. depict a recognisable Myllo Vinyllo machine rather than a generic cleaning box;
4. prefer a slightly elevated 3/4 product view where body depth, controls and working nodes are visible;
5. use a dark/black machine body with readable control/button details;
6. include the brand's recognisable circular visual element / mark where supported by reference;
7. show real operating stages rather than a generic rotating disc;
8. add short dynamic industrial/comic action labels;
9. make the vacuum stage unmistakable;
10. add a concrete before/after groove macro;
11. improve hands, record, sleeve and hardware drawing specificity;
12. keep audio events physically synced to the visible process;
13. keep player repair out of scope.

## Cleaning path

V4 chooses **machine cleaning** as the production path.

The manual-cleaning alternative is explicitly not the V4 branch.

## Dynamic label system

Labels are stage identifiers, not narration.

Working examples to validate against the final storyboard:
- `ОЧИСТКА ПЛАСТИНКИ`
- `МОЮЩИЙ РАСТВОР`
- `ОЧИСТКА КАНАВОК`
- `ВАКУУМ СОБИРАЕТ ЖИДКОСТЬ И ЗАГРЯЗНЕНИЯ`
- `ДО / ПОСЛЕ`
- `ПОВТОРНОЕ ПРОСЛУШИВАНИЕ`

Final wording may be shortened for motion/readability, but every cleaning stage must remain nameable.

## Product-reference rule

Do not invent the V4 machine from memory.

Use the user's actual Myllo Vinyllo materials:
- `Інструкція Myllo Vinyllo / guide-08-01-25.pdf` on Google Drive;
- `Відео Myllo Vinyllo` folder on Google Drive;
- especially the large/legacy Myllo Vinyllo machine videos when modelling the machine-cleaning path.

Where references disagree or are unclear, document the uncertainty rather than silently merging hardware details.

## Target duration

Working target: **32–36 seconds**.

V3's 30 seconds was sufficient for the broad story but too compressed for a legible machine-process explanation.
V4 may spend roughly 12–16 seconds on cleaning if needed.

## Success criterion

A viewer unfamiliar with the previous versions should be able to say:

> “He heard a dirty/noisy record, cleaned it on a record-cleaning machine using solution/brush/vacuum steps, saw that the grooves were cleaner, and then the record played better.”

The cleaning sequence itself must be understandable without brand knowledge.

## Secondary quality target

Move closer to the Butterfly benchmark in:
- authored prop detail;
- recognizable silhouette;
- layered scene depth;
- meaningful simultaneous motion;
- hand/tool interaction;
- camera grammar;
- transformation/transition polish;
- final-work attractiveness.

## Exclusions

- no HTML-player repair;
- no generic abstract morphing in place of product/process depiction;
- no silent return to the V2 “process symbols” approach;
- no FORMAT-01 / C1 / SceneDocument or other SMM-specific pipeline contracts inside the native Procedural Film evaluation.
