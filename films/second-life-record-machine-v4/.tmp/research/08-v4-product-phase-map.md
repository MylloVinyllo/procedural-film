# V4 machine-cleaning phase map

Date: 2026-09-27

This map converts the human review + Myllo sources into the exact semantic stages V4 must make readable.

## Phase A — problem already established

Inherited from V3:
- dirty/problem record;
- first playback;
- crackle/noise;
- human concern.

V4 should preserve or lightly improve these scenes, not spend the majority of new complexity here.

## Phase B — machine reveal

Viewer must recognise:
- this is a dedicated device;
- it is Myllo Vinyllo-branded;
- record sits on top;
- there are two different working nodes;
- there are front controls.

Preferred camera:
- elevated 3/4 front.

Dynamic label candidate:
**ОЧИСТКА ПЛАСТИНКИ**

## Phase C — solution/feed + brush

Physical sequence:
- START → visible rotation;
- supply/brush node moves onto record;
- PUMP → liquid appears at the feed/brush contact;
- brush is visibly pressed to grooves.

Dynamic label candidates:
- **МОЮЩИЙ РАСТВОР**
- then **ОЧИСТКА КАНАВОК**

Visual proof:
- actual brush bristles;
- wet film;
- dirt/fibre movement local to grooves;
- button-stage highlight on the real front plate.

## Phase D — reverse / two-direction cleaning

Physical sequence:
- REVERSE changes rotation direction;
- brush remains physically engaged.

Dynamic micro-label:
**REVERSE / ОБРАТНОЕ ВРАЩЕНИЕ** only if readable without clutter.

V4 may compress duration but should show at least one unmistakable direction change.

## Phase E — vacuum collection

Physical sequence:
- supply node moves away;
- collection/vacuum node swings onto record;
- VACUUM button activates;
- node presses to/contact plane;
- wet liquid + contamination move into the collection slot;
- dry groove reflection appears behind.

Dynamic label:
**ВАКУУМ**
Secondary line if space allows:
**ЖИДКОСТЬ И ЗАГРЯЗНЕНИЯ УДАЛЯЮТСЯ ИЗ КАНАВОК**

This is the most important new explanatory beat.

## Phase F — matched groove before/after

Before:
- same groove geometry;
- dust/fibre/grit in grooves;
- unstable/broken reflection.

After:
- same crop / groove arc geometry;
- contamination substantially reduced;
- reflection stable;
- no magical colour change.

Dynamic label:
**ДО / ПОСЛЕ**

Possible layout:
- vertical split with sliding comparison bar;
- matched hard cut using exact groove geometry;
- comic inset pair.

## Phase G — repeat playback

Inherited V3 proof:
- same turntable;
- same stylus contact;
- cleaner sound;
- relaxed protagonist.

Dynamic label:
**ПОВТОРНОЕ ПРОСЛУШИВАНИЕ**

Keep short; label should not steal the emotional payoff.

## V4 anti-ambiguity gate

A quarter-scale frame from the cleaning sequence must still allow a viewer to answer:
1. what object is shown? → a record-cleaning machine;
2. what stage is active? → solution/brush or vacuum;
3. which hardware is doing it? → left brush/feed node or right vacuum node;
4. what changed? → wet/dirty grooves become dry/cleaner;
5. why do we care? → second playback is better.

If any answer depends only on prior brand knowledge, the scene is not finished.
