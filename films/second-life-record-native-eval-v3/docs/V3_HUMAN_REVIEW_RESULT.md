# V3 Human Review Result

Date: 2026-09-27
Reviewed master: `output/master.mp4`
Production source: `df552f1ded781799f40218d8fec390ab4368d2db`

## Human verdict

V3 is accepted as a **technical pass**.

Compared with V2, the film communicates a recognisable causal story much better:
- a person takes a record;
- notices contamination/debris;
- puts the record on a turntable;
- the contaminated/problem record produces unpleasant sound;
- the record is then moved to a cleaning stage;
- it returns to playback.

The user explicitly considers this the best version so far in terms of carrying an understandable story.

## Main semantic weakness

The cleaning stage is still not sufficiently self-explanatory.

The viewer can infer “this is probably a record-cleaning machine” only because they already know what to look for.

The next version must make the cleaning process readable without that prior knowledge.

## Required V4 changes from the user review

### 1. Make the record-cleaning machine unmistakable

If V4 uses machine cleaning:
- use a recognisable Myllo Vinyllo machine rather than a generic box;
- make the body darker / black;
- move away from the strict top-down view;
- use a slight 3/4 / elevated side angle so the body, controls and working nodes are visible;
- show recognisable buttons / controls;
- include the brand's circular mark / signature visual element;
- show the actual working logic rather than a generic rotating disc.

### 2. Show the process as discrete readable stages

The machine-cleaning path must visibly communicate:
- cleaning solution;
- cleaning/brush/feed action;
- rotation direction / working motion;
- vacuum collection;
- removal of liquid/contamination;
- dry/clean result.

The user specifically wants the vacuum stage to be visually obvious.

### 3. Add dynamic textual action labels

The viewer should not need to guess what a process panel means.

Add short on-screen action labels in an industrial/comic style, for example:
- “Очищаем пластинку”
- “Моющий раствор”
- “Очистка канавок”
- “Вакуум собирает загрязнение”
- “До / после”
- “Повторное прослушивание”

These are not explanatory subtitles for the whole story. They are dynamic stage identifiers attached to the physical process.

### 4. Add a stronger before/after groove comparison

V4 should include a concrete macro comparison:
- zoom into dirty grooves before cleaning;
- zoom into the same/similar groove region after cleaning;
- before: debris/dirt in grooves;
- after: visibly cleaner groove field;
- keep the difference physical and local rather than magical/glowing.

Possible grammar:
- split panel;
- matched macro cut;
- before/after inset;
- sliding comparison line.

### 5. Improve object drawing quality

The user noted visible style/artifact limitations that should be treated as the next visual-quality layer:
- record shape/detail;
- record sleeve;
- hands;
- machine hardware;
- relationship between hand/tool/object.

These do not invalidate V3, but V4 must use a more specific style and better-authored prop/hand construction.

## Branching decision

V4 will use the **machine-cleaning path**, not manual cleaning.

Manual cleaning remains a valid alternate concept, but it is not the primary V4 branch.

The V4 cleaning machine should be based on real Myllo Vinyllo visual/mechanical reference from the user's Drive materials and instruction manual, not invented from memory.

## V4 success criterion

A first-time viewer should be able to say, without prior explanation:

> “He heard a dirty/noisy record, put it on a record-cleaning machine, the machine applied/used cleaning solution and vacuumed the contamination away, the grooves became visibly cleaner, and the record played better afterward.”

The machine stage must be readable even if the viewer has never seen the previous V3 experiment.

## V3 closure

V3 remains frozen as a technical pass.

No further changes should be made to V3 production source.
All cleaning-stage improvements belong to V4.
